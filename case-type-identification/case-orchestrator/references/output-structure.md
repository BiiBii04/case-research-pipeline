# Output Structure — the Integration Template

This is what turns separately-solved sub-questions into one coherent case answer. Fill it in during Step 6 of
`SKILL.md`, after every sub-question from Step 2 has a framework output from Step 5.

```markdown
# Case Structure — [Brief title / one-line description]

## Overall SCQ
Situation: [from Step 1]
Complication: [from Step 1]
Question: [from Step 1 — what the brief is ultimately asking for]

## Overall Objective
[One or two sentences: the single shared goal every sub-answer below has to serve. This is the throughline —
if a reader only reads this line and the Integrated Recommendation at the bottom, they should still get the
shape of the answer.]

## Sub-question 1 — [short name] — Case type: [type, and which skill/framework solved it]
[The sub-framework's output, in whatever structure that framework naturally produces — e.g. a brand-
communication sub-question ends in a Big Idea + IMC/Trade plan + KPIs; a profit-optimization sub-question ends
in a root cause + short/long-term recommendations.]

**Ties back to the Overall Objective because:** [one explicit sentence — don't skip this even when it feels
obvious. This sentence is what makes the difference between an integrated answer and a stapled one.]

## Sub-question 2 — [short name] — Case type: [type]
[same shape]

**Ties back to the Overall Objective because:** [...]

## [repeat for any further sub-questions]

## Integrated Recommendation
[Synthesize — don't just list the sub-answers again. What does the team actually walk into the room and say?
If sub-question 1's recommendation depends on or reinforces sub-question 2's, say so explicitly — e.g. "the
campaign in Sub-question 1 is timed to launch only after the cost fix in Sub-question 2 restores the margin
headroom to fund it." A reader should be able to skip straight to this section and get the whole answer.]
```

## Notes on filling this in

- **If only one type fired (a "pure" case):** this template still applies, it just has one sub-question section
  — keep the Overall SCQ/Objective and the explicit tie-back sentence anyway. It costs one sentence and it's
  what a grader is checking for regardless of how many types are actually in play.
- **If more than one type fired (a mixed case):** the Integrated Recommendation section is where the real
  synthesis work happens — this is usually where mixed-case answers succeed or fail. Budget real time for it,
  not just the last five minutes.
- **If a sub-question fell back to general structuring** (`SKILL.md` Step 5/7, no dedicated skill or nothing
  fired clearly) because no matching skill exists yet or nothing fired clearly, its section still gets a case
  type label — write it as "general structuring (no dedicated skill)" — and still needs the same explicit
  tie-back sentence.
- See `worked-mixed-example.md` for this template filled in end to end on a constructed brief.
